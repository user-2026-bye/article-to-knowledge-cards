# make-knowledge-cards

## 项目解决什么问题

读完文章或笔记后「读时明白、过后就忘」是常见的学习痛点。本项目提供了一个符合 [Agent Skills](https://agentskills.io) 开放标准的 AI 技能（Skill）：把用户粘贴的文章或本地 Markdown / TXT 文件自动提炼成 **5~8 张结构化知识卡片**，每张卡片聚焦一个知识点，方便学习、背诵与复习。该技能可被支持此标准的 AI 客户端（如 Codex）发现并复用。

## 主要功能

- **输入**：用户直接粘贴的文章文本，或本地 `.md` / `.txt` 文件路径
- **输出**：5~8 张知识卡片，每张卡片包含四个要素：
  - 标题
  - 核心知识（一句话概括本知识点）
  - 简明解释（2~4 句，只使用原文信息）
  - 例子或自测问题（优先给原文中的例子；原文没有合适例子时出自测题并附参考答案）
- **质量规则**：
  - 只提取真正重要的知识点（对理解主题必不可少、包含具体信息、独立成立）
  - 一张卡片只讲一个知识点；自动去重、合并重复内容
  - 不编造原文没有的信息（包括自测题的参考答案）
  - 信息不足时不强行凑数：不足 5 个知识点时输出实际数量并如实说明
- **语言**：默认与原文一致；用户可要求中文 / 英文 / 双语输出
- **不支持的输入**：网页抓取（仅给 URL）、PDF、Word（.docx）、Anki 导出、图形界面

## 安装方法

本技能是**纯指令型 Skill，无脚本、无依赖**，安装只需三步：

1. **前置条件**：一个支持 Agent Skills 开放标准的客户端（如 Codex 等）
2. **拷贝目录**：将本仓库的 `skills/make-knowledge-cards/` 目录整体复制到该客户端的 skills 目录（不同客户端的目录位置不同，请参照其文档）
3. **重启客户端**：使其加载并发现新技能

安装完成后，即可在客户端中按技能名称触发它。

## 使用方式

在客户端中直接下达指令：

**方式一：粘贴文章**

```
用 make-knowledge-cards 把这篇文章做成知识卡片：
<粘贴文章内容>
```

**方式二：指定本地文件**

```
把 articles/water-cycle.md 转成知识卡片
把 notes/随手记.txt 做成知识卡片
```

**指定输出语言（可选）**

```
把这篇文章做成知识卡片，用英文输出
```

## 输入与输出示例

**输入**（用户粘贴的短文）：

> 水在标准大气压下的沸点是 100 摄氏度。海拔越高，气压越低，水的沸点也会随之降低。例如在海拔 3650 米的拉萨，水的沸点约为 88 摄氏度。

**输出**：

```markdown
# 《水的沸点与气压》知识卡片

**共 2 张**

原文信息有限，仅提炼出 2 个独立知识点。

### 卡片 1：标准大气压下的沸点
- **核心知识**：标准大气压下水的沸点是 100 摄氏度。
- **简明解释**：沸点是液体沸腾时的温度；气压为标准大气压时，水的沸点为 100 摄氏度。
- **例子或自测问题**：自测：在标准大气压下，水的沸点是多少摄氏度？（答案：100 摄氏度）

### 卡片 2：海拔越高沸点越低
- **核心知识**：海拔越高、气压越低，水的沸点随之降低。
- **简明解释**：气压降低使水更易沸腾，因此高海拔地区水的沸点低于 100 摄氏度。
- **例子或自测问题**：例子：在海拔 3650 米的拉萨，水的沸点约为 88 摄氏度。
```

> 注：这篇短文只有 2 个独立知识点，因此只输出 2 张卡片并如实说明，不强行凑满 5 张；信息充足的文章通常输出 5~8 张。

## 开发与验证

- 使用官方 `openai/skills` skill-creator 工具（`init_skill.py`）初始化，格式符合 Agent Skills 开放标准
- 官方校验脚本 `quick_validate.py` 验证通过（结果：`Skill is valid!`）

```bash
python quick_validate.py skills/make-knowledge-cards
```

> Windows 下若提示 UnicodeDecodeError，先设置环境变量 `PYTHONUTF8=1` 再运行。
